## 🎯 What The App Does

### For Users:
1. **Setup**: Create personalized arc (70-90 days, 3-5 goals, custom name)
2. **Track**: Check off daily goals with visual progress
3. **Analyze**: View streaks, stats, timelines
4. **Reflect**: Write journal entries with mood & photos
5. **Customize**: Choose theme, set notifications, export data

### Key Differentiators:
- ❄️ **Personal**: Beyond just numbers - captures emotions
- 🎯 **Flexible**: Edit goals, themes, preferences
- 📊 **Complete**: Progress tracking + personal journaling
- 🔒 **Private**: All data local, no cloud required
- 📤 **Portable**: Export your data anytime
